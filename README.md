Rigorous structural investigation of the Erdos-Moser problem: unit distances among vertices of a convex polygon

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/unit-distances-in-convex-position.git
cd unit-distances-in-convex-position
python "src/aligned_lens.py" --help
```
